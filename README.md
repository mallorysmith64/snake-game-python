# snake-game-python
🐍 Vertical Scrolling Snake
A fast-paced twist on the classic Snake game where the screen automatically scrolls downward. Don't get left behind, and don't hit the walls! Built with Python, Pygame, and Pygbag for web compatibility.

🎮 How to Play
Objective: Eat the strawberries to grow and increase your score.

Controls:

Arrow Keys: Change direction (Up, Down, Left, Right).

Mouse Click: Click the "Play Again" button on the Game Over screen.

🚀 Running the Game
Method 1: Desktop (Python)
Make sure you have Pygame installed:
pip install pygame

Then run the script directly:
python main.py

Method 2: Web Browser (Pygbag)
To run the game in your browser using WebAssembly:
1. pip install pygbag </br>

2. python3 -m pygbag snakegame </br>

View in Browser: Open http://localhost:8000
